Innovations

What makes Guardian different

↔

Handoff architecture

Agents do not call each other directly. They request supervisor-dispatched investigations, preventing stale reads and hidden coupling.

◈

Evidence-first reasoning

Every finding can resolve to raw input, API response or detector output. AI claims are separate from verified facts.

⌁

Install-time awareness

Malicious and tampering findings retain full risk even when source reachability is absent because install scripts execute separately.

⇄

Alias deduplicating

CVE, GHSA and OSV records merge through union-find so one component gets one canonical vulnerability identity.

◇

Source conflict preservation

Disagreements in severity, ranges or fixes remain visible instead of being silently overwritten.

⛨

Defense-in-depth sandbox

Validation uses disposable containers, no host environment secrets, no network, read-only mounts and dropped Linux capabilities.
